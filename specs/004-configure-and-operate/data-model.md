# Data Model: Configure and operate it

Five entities. Three are new, two are existing records that gain a field. None of
them is a database — this daemon's durable state is tmux user options and one
file it never writes.

---

## 1. Configuration file

The operator's own statement of how this daemon behaves. **The daemon reads it
and never writes it** (FR-008).

| Property | Value |
|---|---|
| Default location | `$XDG_CONFIG_HOME/crswd/config`, falling back to `~/.config/crswd/config` |
| Override | `--config <path>` flag, or `CRSW_CONFIG_FILE` |
| Backup consulted on failure | `config.bak` in the same directory (FR-010) |
| Encoding | UTF-8, LF or CRLF line endings |
| Absent | Not an error (FR-003) |

### Fields

Every key is its environment variable minus `CRSW_`, lower-cased. The table is
therefore generated by rule, not maintained by hand; these are the keys that
exist as of this milestone.

| Key | Type | Secret | Notes |
|---|---|---|---|
| `version` | integer | no | Schema the file was written against. Absent means 1. |
| `listen` | string | no | |
| `shared_secret` | string | **yes** | May contain `#` and `=`. See the grammar. |
| `access_allowed_emails` | list | **yes** | Names who may reach this daemon. |
| `allowed_roots` | list | no | The containment boundary. |
| `start_commands` | list | no | `name=command` pairs, comma-separated. |
| `session_lifetime` | duration | no | |
| `idle_timeout` | duration | no | Negative disables idle reaping. |
| `pane_bound` | integer | no | New this milestone (FR-052). |
| `discover_roots` | boolean | no | New this milestone. Off by default (FR-041). |

### Validation

Validation is **not** defined here, and that is the point of the design: a value
from the file goes through `config.LoadFrom`, which is where every bound, every
default and every refusal already lives. The file layer's own refusals are only
those that are about *the file*:

| Refusal | Condition | FR |
|---|---|---|
| Unknown key | The key maps to no environment variable | FR-005 |
| Renamed key | The key is in `renamedKeys` — accepted, warned, both spellings named | FR-006 |
| Malformed line | A non-comment, non-blank line with no `=` | FR-005 |
| Too permissive | Mode has any of `0o077` set **and** the file contains a secret key | FR-007 |
| Future schema | `version` exceeds `SchemaVersion` | FR-009 |
| Repeated key | The same key appears twice | FR-005 |

## 2. Configuration source (provenance)

New. Which of flag, environment, file or default supplied each value — recorded
by the precedence shim as it answers lookups, because the shim is the only code
that knows (research R4).

```go
type Source uint8

const (
	SourceDefault Source = iota // nothing supplied it
	SourceFile
	SourceEnv
	SourceFlag
)
```

| Property | Value |
|---|---|
| Keyed by | The environment-variable name, e.g. `CRSW_ALLOWED_ROOTS` |
| Populated | Once, during `Load`, never mutated afterwards |
| Read by | The settings page, and nothing else |

**Relationship**: one `Source` per key; a key never has two. This is the record
that makes FR-018 and SC-004 answerable — "why is my change not applied?" is
answered by a value that says it came from the environment when the operator
edited the file.

## 3. Session mode

Whether a session is reachable from claude.ai. **Derived, not stored** (research
R5).

```go
func (s Session) Mode() Mode  // derived from s.StartCommand
```

| Property | Value |
|---|---|
| Values | `ModeLocal`, `ModeRemote` |
| Derived from | `Session.StartCommand`, which is a configured **name** and never a command line |
| Which names mean remote | Configuration — a start command whose name is listed in `remote_start_commands` |
| Persisted as | tmux user option `@crswd-start`, joining the four that already survive a restart |

### State transitions

```
ModeLocal  --toggle-->  ModeRemote
ModeRemote --toggle-->  ModeLocal
```

A transition **ends and restarts the process inside the pane**. It must:

- preserve the tmux session, its window, and its scrollback (FR-028)
- pass `--continue` so the conversation survives (FR-028)
- require a deliberate confirming step (FR-029)
- refuse rather than resume the wrong conversation where "the last conversation
  in this directory" is ambiguous (FR-032)

The session identifier, credential and lifetime are unchanged by a transition —
it is the same session in a different mode, not a new one.

## 4. Prior conversation

An identifier and a time, offered for resume. **Never its contents** (FR-034).

```go
type Conversation struct {
	ID       string    // as Claude Code names it
	Modified time.Time
}
```

| Property | Value |
|---|---|
| Source | Claude Code's own conversation store, read as a fact about the host |
| Operation | A **directory listing**. No file is ever opened. |
| Scope | Only for a working directory under an approved root (FR-035) |
| Absent store | Offers nothing. Not an error. |
| Default | Starting fresh, always — a resume is something the operator chose (FR-037) |

**Relationship**: a resumed conversation still produces a **new session record**
with its own identifier, credential and lifetime (FR-036). The conversation is an
input to starting a session, not an alternative to one.

This entity is the narrowest new filesystem surface in the milestone, and its
narrowness is the security property: a listing cannot leak a transcript.

## 5. Directory suggestion

A convenience for the create form. **Never an authorisation** (FR-042).

| Property | Value |
|---|---|
| Explicit source | A configured list |
| Discovered source | Subdirectories of the approved roots, behind `discover_roots`, off by default (FR-041) |
| Depth | One level below each approved root |
| Rendered as | `<option>` elements inside a `<datalist>` |
| Validation | **None of its own.** A chosen path is validated exactly as a typed one is. |

The last row is the entity's whole security story. The suggestion list is
presentation; the allowlist is the control. A path appearing in the list grants
nothing, and a path absent from it is still acceptable if the operator types it
(FR-040).

## Entity relationships

```
Configuration file ──parsed by──> precedence shim ──records──> Configuration source
                                        │                              │
                                        ▼                              ▼
                                     Config  ─────────────────>  Settings page
                                        │
                          ┌─────────────┴──────────────┐
                          ▼                            ▼
                 Directory suggestion            Session record
                          │                            │
                          └──────> create form <───────┤
                                        ▲              │
                                        │              ▼
                                 Prior conversation  Session mode (derived)
```

Read the diagram for what it does *not* contain: no path from the settings page
back to the configuration file (editing is out of scope, and a route that does
not exist cannot be exploited), and no path from a browser to a command line
(FR-030, in both directions).
