{{/* What this daemon is, on every page that renders it. The operator asked for it after watching a deploy and having no way to tell from the interface whether the binary in front of them was the one that had just been built. That question has an answer the daemon already knows — `crswd --version` prints it — and until now the only way to ask was over a shell on the host, which is the thing this product exists to avoid needing. It reads the same `buildinfo.Version` the command line does, through a template function rather than a field on eight view structs (render.go). A build that no release produced says `dev`, which is the honest answer and is exactly what the flag says too: the footer cannot claim a release the binary does not. Not a link, deliberately. There is a settings page one click away that says far more, and a version that navigated somewhere would be a control rather than a fact. Muted and small, because it is the least important true thing on the page — and because a footer that competes with the fleet has misunderstood which of them the operator came for. */}}
